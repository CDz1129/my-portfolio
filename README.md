# My Portfolio

> 本地优先（local-first）的个人资产管理工具。**数据永不离开你的浏览器。**

[English](./README.en.md) · 中文

用中文 / 英文界面管理 A 股、港股、美股、加密货币与各类资产负债。没有账号、没有登录、没有云端数据库，服务器不保存任何用户数据。

## 这是什么

一个**本地优先的个人资产记录与展示工具**。把散落在各个账户里的资产——现金、投资、固定资产、应收款、负债——集中到一处看清：净资产、资产配置、净值走势。

## 为什么做这个

- 出于自身需求：想要一个能**一眼看清个人资产**的地方。
- 市面上的同类 App 大多需要付费，而且价格不低，于是干脆自己做一个。
- **核心卖点：数据只存在你自己的浏览器里，永不离开本地。** 代价同样明确——**离开这个浏览器，数据也就没有了**。所以请养成用「设置 → 备份与恢复」导出 JSON 留档的习惯。

## 为什么行情默认一个季度才更新一次

盯盘的节奏不同，长期结果往往也不同：每秒刷新的、每天看的、一年看一次的，常常是后者更从容。这个项目希望你买入的资产都是**能让你安心睡觉**的——一个季度看一次，也不会因此担心。少一点频繁看盘的杂念，把注意力留给生活。

> 因此自动更新默认「每季度一次」，并保留随时手动更新；频率可在设置中调整。

## 这不是什么

**这不是一个生活记账软件。** 它确实会记录资产变动（收入 / 支出 / 转账 / 买卖 / 余额调整），但它的本质是**资产盘点与展示**，与按笔记录日常开销的记账 App 完全不同。如果你想记录每天的衣食住行、做分类预算，请选择专门的记账软件。

## 隐私承诺

大多数记账 / 资产管理应用需要注册账号，把你的资产明细上传到别人的服务器。My Portfolio 反过来：**所有数据只存在于你自己的浏览器**（IndexedDB），代码完全开源可审查。

- 账户、持仓、流水、设置全部存储在浏览器 IndexedDB（数据库名 `my-portfolio`）。
- 演示数据存放在独立的数据库 `my-portfolio-demo`，与你的真实数据完全隔离，可随时切换查看。
- 行情服务是**无状态代理**：只向行情源转发公开请求，从不接收、记录或存储你的持仓与账目。
- **无账号、无登录、无追踪、无统计。**
- 唯一的外发请求是获取公开行情（股价、汇率、代码搜索），其中不含任何个人信息。

数据绑定在「同一浏览器 + 同一域名」之下：清除站点数据、无痕窗口或更换浏览器都会得到一份独立数据。请定期用「设置 → 备份与恢复」导出 JSON 备份。

## 功能

- **多账户**：流动资金、投资、固定资产、应收款、负债五类，支持分组、归档与自定义颜色。
- **持仓管理**：代码搜索自动补全名称 / 市场 / 币种并拉取现价，记录股数、成本、现价；持仓按市值倒序。
- **流水记录**：收入、支出、转账、买入、卖出、余额调整。
- **总览**：净资产、总资产 / 总负债、资产配置、投资表现、净资产走势。
- **两种配置视角**：按**账户类型**，或按**流动性**（券商现金计入流动资产，持仓计入投资资产）。
- **多币种**：12 种常用货币；首页顶部可一键切换总资产显示币种，统一换算。
- **中英双语**：设置里一键切换，界面与数字格式随之切换。
- **行情同步**：自动更新频率可选（每天 / 每周 / 每月 / 每季度 / 从不），默认每季度，随时手动更新。
- **可折叠分组**：首页与账户页的类型分组可收起 / 展开并记住状态。
- **数据管理**：CSV 导出（流水）、完整 JSON 备份与恢复、需输入确认的安全清空。
- **PWA**：可安装到桌面 / 手机，支持离线；深浅色主题。

## 技术栈

- **前端**：React 18 + TypeScript + Vite 5
- **样式**：Tailwind CSS
- **本地存储**：Dexie（IndexedDB）+ dexie-react-hooks（响应式实时查询）
- **图表**：Recharts · **图标**：lucide-react · **PWA**：vite-plugin-pwa
- **测试**：Vitest + Testing Library
- **行情代理**：Node（本地）与 Cloudflare Worker（云端）共用同一套逻辑

## 架构要点

- **事件溯源账本**：账户只保存 `openingBalance`，其余余额由流水回放得出，历史与趋势可自由重算。
- **演示数据隔离**：演示数据在独立数据库；旧版本曾混入真实库的演示数据会在启动时自动迁移隔离。
- **行情降级链**：Yahoo 为主，腾讯（A / 港股 / 美股，GBK 解码）与 OKX（加密货币）逐级兜底。
- **i18n**：轻量自研词典 + React Context，无第三方依赖。
- **设置与数据分离**：主货币、汇率、主题、语言、同步频率属于应用偏好，始终保存在真实库并跨视图共用。

## 快速开始

要求 Node 22+（Cloudflare 部署所用的 wrangler 需要 Node 22 以上）。

```bash
npm install
npm run dev        # 开发模式 http://localhost:5173
npm start          # 构建并以本地 Node 服务运行 http://localhost:4173
npm test           # 全部测试
```

常用脚本：

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | Vite 开发服务器（含行情代理中间件） |
| `npm run build` | 类型检查 + 生产构建 |
| `npm start` | 构建并启动本地服务（默认 4173 端口） |
| `npm run serve` | 仅启动本地服务（不重新构建） |
| `npm test` | 运行全部测试 |
| `npm run coverage` | 覆盖率报告 |
| `npm run deploy` | 构建并部署到 Cloudflare Workers |
| `npm run service:install` | macOS 开机自启（launchd） |

## 语言与货币

- **语言**：设置 → 通用 → 语言，可选 中文 / English。数字与日期格式随之切换（`zh-CN` / `en-US`）。
- **主货币**：设置里选择，或在首页顶部净资产卡片右上角快速切换。所有资产都会换算成该货币显示。
- **汇率**：只列出你实际用到的外币（账户或持仓涉及的），用于把外币资产换算成主货币，仅在总资产、配置、趋势的计算中使用。

## 行情数据源

| 用途 | 数据源 |
| --- | --- |
| 港股 / 美股 / A 股报价 | Yahoo Finance，失败时降级到腾讯行情 |
| 加密货币报价 | Yahoo，失败时降级到 OKX |
| 汇率 | open.er-api.com |
| 代码搜索 | 腾讯 smartbox + Yahoo，去重合并 |

均为公开数据。受限网络下逐个降级，不影响本地记账；不配置行情源时价格可完全手动录入。

## 部署

### Cloudflare Workers（推荐，前后端一体）

仓库已包含 `worker.mjs` 与 `wrangler.toml`，同一个 Worker 既托管前端静态资源，也处理 `/api/*`：

```bash
npx wrangler login
npm run deploy
```

也可以用 Cloudflare 的 Git 集成：Workers & Pages → 你的 Worker → Settings → Builds → Connect to Git，构建命令 `npm run build`，部署命令 `npx wrangler deploy`，之后每次 push 自动重新部署。

### GitHub Pages（仅前端）

GitHub Pages 只能托管静态文件，无法运行 `/api`。需要设置 `base: '/<仓库名>/'`、为 SPA 路由加 `404.html` 回退，并把行情代理部署到别处后用 `VITE_MARKET_API` 指向它。不含行情时本地功能完全可用。

## 接口保护

- **限流**：`wrangler.toml` 内置 Cloudflare Rate Limiting binding（默认每 IP 60 次 / 60 秒，作用于 `/api/*`），无需自定义域名；删除 `[[ratelimits]]` 段即可关闭。
- **可选令牌**：设置 Secret `API_TOKEN`（`npx wrangler secret put API_TOKEN`）后请求需带 `X-API-Token`；前端通过构建变量 `VITE_MARKET_API_TOKEN` 提供同值。注意静态前端里的令牌只能阻挡爬虫，并非密钥。
- **边缘缓存**：报价 / 汇率 / 搜索响应在边缘缓存 60–300 秒，减少回源。

## 数据与备份

- 数据默认只在本浏览器。迁移或留档请用 **设置 → 备份与恢复** 导出 JSON（含全部账户、持仓、分组、流水与设置）。
- 恢复会覆盖当前数据；非本应用的 JSON 会被拒绝。
- 用户数据从不上传服务器；仓库中不含任何数据文件。

## 目录结构

```
src/
  domain/       纯业务逻辑：类型、货币换算、事件溯源账本、总览视图模型
  db/           Dexie 数据库与仓储（CRUD、CSV、备份/恢复、演示数据）
  store/        应用用例（actions）、数据模式（真实 / 演示）与同步
  i18n/         中英文词典与 Provider
  components/   UI 组件（表单、图表、搜索、导航、模式切换条、账户首字徽标）
  pages/        页面路由
  lib/          行情 API 客户端、主题、折叠状态、工具
server/         行情代理（Node 服务 + Vite 中间件 + 共用 market 逻辑）
worker.mjs      Cloudflare Worker 入口（静态资源 + /api）
wrangler.toml   Cloudflare 部署配置
scripts/        macOS launchd 服务安装 / 卸载、图标生成
```
